# AI POS App

React Native tablet-first client for the AI POS MVP.

## Stack

- Expo + React Native + TypeScript
- React Navigation
- NativeWind / Tailwind RN
- Zustand
- TanStack Query
- Axios
- react-hook-form
- react-native-mmkv

## Scripts

```bash
pnpm install
pnpm start
pnpm android
pnpm typecheck
```
